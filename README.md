# Speech Emotion Recognition Using CNN

## Project Overview
This project uses Deep Learning to identify human emotions from speech audio recordings.

## Dataset
RAVDESS Speech and Song Dataset.

## Technologies
- Python
- TensorFlow
- Keras
- Librosa
- NumPy
- Scikit-learn
- Matplotlib

## Feature Extraction
MFCC (Mel-Frequency Cepstral Coefficients).

## Model
Convolutional Neural Network (CNN).

 ## Emotions Recognized

1. Neutral
2. Calm
3. Happy
4. Sad
5. Angry
6. Fearful
7. Disgust
8. Surprised
